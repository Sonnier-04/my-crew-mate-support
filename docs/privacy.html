개인정보 처리방침

My Crew Mate는 사용자의 근무와 일상을 편리하게 기록하고 관리할 수 있도록 돕는 iOS 앱입니다. 사용자의 기록은 기기에 저장되며, 이 페이지에서는 정보의 이용과 백업·복원, 보관 및 삭제, 문의 방법을 안내합니다.

한눈에 보는 개인정보 처리

  • 기기에 기록 저장
  • 운영자 서버 자동 전송 없음
  • JSON 백업은 비암호화

1. 앱에서 처리하는 정보

My Crew Mate는 근무표 작성 및 관리를 위해 다음 정보를 처리합니다.

  • 날짜별 근무 기록과 메모
  • 근무 종류의 이름, 색상 및 표시 상태
  • 사용자가 입력한 이름과 별명
  • 앱 시작 안내 진행 상태
  • 테마, 대시보드와 빠른 입력의 배치 등 사용자 설정

이 정보는 달력과 근무 현황을 표시하고, 사용자가 원하는 설정을 유지하는 데 사용됩니다. 메모나 근무 종류 이름에 직접 입력한 개인정보도 저장될 수 있습니다.

2. 정보의 저장과 이용

근무 기록과 날짜별 메모, 근무 종류는 사용자의 iPhone에 저장됩니다. 이름과 별명, 테마, 화면 배치 등 앱 설정도 기기에 저장됩니다.

  • 계정 가입 없이 사용할 수 있습니다.
  • 인터넷 연결 없이 근무 기록을 관리할 수 있습니다.
  • 앱에 저장된 근무 기록을 운영자 서버로 자동 전송하지 않습니다.
  • 앱 자체의 클라우드 동기화 기능은 제공하지 않습니다.

사용자가 직접 백업 파일을 내보내거나 공유하면, 선택한 저장 위치나 외부 서비스로 파일이 전달될 수 있습니다.

3. 백업 및 복원

사용자는 앱의 백업 기능으로 JSON 파일을 내보내고, 파일을 선택해 기록을 복원할 수 있습니다.

백업에 포함되는 정보

  • 근무 기록과 날짜별 메모
  • 근무 종류 정보 및 과거 기록 표시를 위해 보관된 근무 종류 정보

백업에 포함되지 않는 정보

  • 프로필 이름과 별명
  • 테마, 화면 배치 등 앱 설정
백업 파일 보관 안내

JSON 백업 파일은 암호화되어 있지 않습니다. 파일에 접근할 수 있는 사람은 근무 기록과 메모를 읽을 수 있으므로, 보관 위치와 공유 대상을 신중하게 선택해 주세요.

복원 시에는 선택한 파일의 내용을 미리 확인할 수 있습니다. 앱은 기존 기록의 안전 사본을 만들고 필요한 검증과 확인 절차를 거친 뒤 기록을 백업 내용으로 교체합니다. 교체되는 항목은 백업 파일의 버전과 내용에 따라 달라질 수 있습니다.

복원을 취소하거나 완료한 뒤에도 내부 복구 사본과 복원 이력에 기존 기록 또는 복원 대상 기록이 남아 있을 수 있습니다.

4. 정보의 보관 및 삭제

근무 기록과 날짜별 메모는 사용자가 앱에서 수정하거나 삭제할 수 있습니다. 다만 현재 기록을 삭제해도 이미 만든 JSON 백업, 내부 복구 사본, 복원 이력에는 같은 내용이 남아 있을 수 있습니다.

설정에서 삭제한 근무 종류는 과거 기록을 표시하기 위해 보관되며 새 백업에도 포함될 수 있습니다. 이전 버전에서 가져온 기록의 원본과 이전 이력도 기기 안에 남아 있을 수 있습니다. 현재 앱에는 내부 복구 사본과 복원 이력을 자동으로 정리하거나 개별 삭제하는 기능이 없습니다.

백업 파일을 내보내거나 선택할 때 임시 파일이 생길 수 있습니다. 앱은 작업 완료 시 임시 파일을 자동 삭제하지 않으며, 파일의 실제 정리 시점은 저장 위치와 iOS 동작에 따라 달라질 수 있습니다.

iPhone에서 앱을 삭제하면 해당 기기의 앱 내부 기록과 설정이 제거됩니다. 다만 iPhone의 ‘앱 정리하기’ 기능은 문서와 데이터를 보존하며, iCloud 기기 백업이나 앱 밖에 따로 저장한 JSON 파일은 앱 삭제 후에도 남아 있을 수 있습니다.

외부에 내보낸 백업 파일은 사용자가 해당 저장 위치에서 직접 삭제해야 합니다. 앱을 삭제하거나 기기를 바꾸기 전에 필요한 기록을 별도로 백업하고 파일이 정상적으로 열리는지 확인해 주세요.

5. 외부 서비스 이용

My Crew Mate는 근무 기록을 운영자 서버에 자동으로 동기화하지 않습니다. 사용자가 iCloud Drive 등 외부 저장 서비스에 백업을 보관하거나 다른 사람과 공유하면, 해당 서비스나 수신자가 파일을 보관할 수 있습니다. 외부 서비스의 보관과 삭제는 해당 서비스의 정책과 사용자 설정에 따릅니다.

Apple의 iCloud 기기 백업을 이용하는 경우 앱 데이터 일부가 기기 백업에 포함될 수 있습니다. 이는 My Crew Mate가 제공하는 클라우드 동기화 기능과 다르며, 실제 백업·복원되는 항목은 iPhone 설정과 복원 환경에 따라 달라질 수 있습니다.

개인정보 문의를 이메일로 보내는 경우, 이메일 주소·문의 내용·첨부파일은 이메일 서비스에서도 처리될 수 있습니다. 이는 앱의 근무 기록이 자동으로 운영자에게 전송된다는 의미는 아닙니다.

6. 개인정보 관련 문의

사용자는 앱 이용 및 개인정보 처리에 관해 문의하거나, 운영자가 보유한 개인정보의 열람·정정·삭제 등을 요청할 수 있습니다. 기기에만 저장된 근무 기록은 운영자가 원격으로 열람하거나 직접 삭제할 수 없습니다.

문의 처리를 위해 보낸 사람의 이메일 주소, 문의 내용 및 사용자가 직접 첨부한 파일을 이용합니다. 문의 이메일과 첨부파일은 문의 처리 완료일로부터 90일간 보관한 뒤 삭제합니다. 법령상 별도의 보관 의무가 있는 경우에는 해당 법령에서 정한 기간 동안 보관한 뒤 삭제합니다.

개인정보가 포함된 근무 기록이나 JSON 백업 파일은 문의 메일에 첨부하지 않는 것을 권장합니다.
