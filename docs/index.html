시작하기

근무 기록을 시작해 보세요

근무 종류를 정하고 날짜별로 기록한 뒤, 월간 현황에서 살펴보세요.

01

나에게 맞는 근무표 설정

근무 종류의 이름과 색상을 설정하세요. 주간, 야간, 비번 등 내 근무 환경에 맞게 구성할 수 있습니다.

02

날짜별 근무 기록

달력에서 날짜를 선택해 근무 종류를 직접 기록하세요. 근무 일정은 자동으로 반복 입력되지 않습니다.

03

날짜 메모 작성

기억해야 할 일정이나 중요한 내용을 날짜별 메모로 남길 수 있습니다.

04

근무 현황 확인

달력에서 한 달의 근무 기록을 살펴보세요.

백업 및 복원

기록을 백업하고
필요할 때 복원하세요

My Crew Mate는 JSON 파일을 이용한 데이터 백업과 복원을 지원합니다.

파일에 포함되는 정보, 암호화 여부, 앱 안에서의 조작 단계는 최종 앱 확인 후 구체적으로 안내할 예정입니다.

공유 전 파일 내용을 확인하세요

백업 파일을 다른 앱이나 사람에게 보내기 전, 어떤 정보가 담겼는지 확인하고 보관 위치를 신중히 선택하세요.

복원 전에는 앱의 최신 안내를 확인하세요. 미리보기 여부와 복원 후 현재 기록에 미치는 영향은 최종 앱 검증 후 안내할 예정입니다.

도움말

자주 묻는 질문

근무 일정이 자동으로 반복 입력되나요?

아니요. 근무 일정은 자동으로 반복 입력되지 않으며, 사용자가 날짜별로 직접 기록합니다.

인터넷 연결 없이 사용할 수 있나요?

앱은 오프라인 기반 데이터 저장을 제공합니다. 인터넷 없이 사용할 수 있는 기능의 범위는 최종 앱에서 확인한 뒤 안내할 예정입니다.

앱을 삭제하거나 기기를 바꾸기 전에 무엇을 확인해야 하나요?

앱 삭제 또는 기기 변경 시 기록이 어떻게 처리되는지는 최종 앱 확인 후 안내할 예정입니다. 기록이 필요하다면 진행 전에 앱의 JSON 백업 기능과 완료 안내를 확인하세요.

다른 iPhone에서 기존 기록을 복원할 수 있나요?

JSON 파일을 이용한 백업 및 복원 기능을 제공합니다. 기기 간 파일 이동 방법과 복원 시 현재 기록에 미치는 영향은 앱의 최신 안내를 확인한 뒤 진행하세요.

근무 기록이 외부 서버로 전송되나요?

외부 서버 전송 여부는 앱과 연동 서비스의 최종 점검 후 확정하여 안내할 예정입니다. 현재는 전송 여부를 단정하지 않습니다.
